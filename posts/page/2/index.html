Prototyping

What design questions did you intend to answer with your prototypes? Our prototypes aimed to answer two questions: (1) Is the semester grid layout intuitive as a way to enter and visualize a four-year plan? (2) Does showing requirement completion status before vs. after a user action help or distract students from planning? How did you design your prototypes and subsequent user studies to address these questions? We built a paper prototype of the 4×2 semester grid (four columns for two semesters per academic year, two rows for upper and lower half of the page) and tested it with three students. For the live-vs-on-demand question we built two versions of the requirements panel — one that updated after every course added and one that only updated when the user clicked “Check Requirements” — and alternated which version each test user saw first. We asked users to think aloud while filling in a sample plan and observed where they paused, re-read, or expressed confusion. ...

Architecture

Medium-Scale Architecture src/App.jsx (lines 34–82), server/index.js, src/components/semestersTable.jsx, src/components/major_requirements.jsx What architectural pattern does your program employ? The project uses a REST API + Single Page Application (SPA) pattern. The backend exposes a stateless JSON API over HTTP; the frontend is a React SPA that fetches from those endpoints and manages all interactive state locally. This is a client-server separation where neither side knows about the other’s internal structure — the server just returns JSON, and the client just consumes it. ...

What techniques did you employ to discover users’ needs? The team conducted informal interviews with Grinnell students — specifically students who had recently gone through the process of planning their four-year course schedule. Conversations focused on pain points with the existing tools (the registrar’s worksheet and the catalog PDF), how students currently track prerequisites, and where they felt uncertain about whether they were on track for their major.
